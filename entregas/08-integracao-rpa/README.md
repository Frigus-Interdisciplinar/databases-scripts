# Integracao RPA (repositorio separado)

O orquestrador e mantido em outro repositorio e foi explicitamente excluido desta publicacao. Para a demonstracao integrada, documentar nele o banco legado de origem, checkpoints, mapeamento para o modelo Frigus, staging, validacoes de PK/FK/duplicidade, commit atomico, retry idempotente, dead-letter/log de falhas e reconciliacao de contagens. Este repositorio cobre o schema, Data Mart, objetos SQL e evidencias do banco de destino.
